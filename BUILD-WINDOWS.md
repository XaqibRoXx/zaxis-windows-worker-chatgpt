# Build Zaxis Worker for Windows

The included GitHub Actions workflow builds the app on a real Windows runner.

1. Push this source to a GitHub repository.
2. Open **Actions → Build Windows → Run workflow**.
3. Download the artifact **Zaxis-Worker-Windows-x64**.
4. Extract the ZIP and double-click **Zaxis Worker.exe**.

No terminal is required to USE the application.

The current build is portable. A signed NSIS/MSI installer should be produced after a Windows code-signing certificate and release/update location are configured.
